# Approved Emmaus artwork

This illustration layer starts at commit `3c6c972`. The original page structure,
reader, notes, memorisation controls, reference tools and background are retained.

The five PNGs in `public/art/` are the original approved ImageGen outputs, kept
unchanged. The stories sheet is the corrected version with five loaves and two
fish. `lib/artwork.js` frames each drawing without the concept-sheet labels.
Next's image optimizer caches a shared image per sheet. An SVG colour filter
renders the ink in the site's cream colour and makes the paper transparent.
Decorations are hidden from screen readers and do not intercept clicks. The
brand links and homepage heading retain the accessible name “Emmaus”.
